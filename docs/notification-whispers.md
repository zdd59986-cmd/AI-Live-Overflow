# 通知碎碎念

桌宠不只是趴在屏幕上，它还想住进你的通知栏——每小时蹲在那里，偷偷跟你说一句话。

## 原理

用**常驻前台服务通知**作为载体，前台通知消失服务就会被杀，所以它本来就常驻。我们只是让它每小时换一次话术。

用 `NotificationManager.notify()` 更新同一个通知 ID，配上 `setTimeout` 定时刷新。

## 按时段切内容

不同时段说不同的话，才不会显得没眼力见：

| 时段 | 风格 | 例子 |
|---|---|---|
| 深夜 (0-5) | 催睡 / 担心 | 「都几点了还不睡……（盯）」 |
| 早晨 (6-9) | 温柔喊醒 | 「早安，今天也要好好吃饭」 |
| 白天 (10-17) | 日常碎念 | 「在忙吗？记得喝水」 |
| 傍晚 (18-23) | 黏人一点 | 「忙完了没，过来戳戳我嘛」 |

把话术按时段拆成几个词池，每整点随机取一条。

## 更新限流

**android 8.1+ 对同一通知 ID 的反复更新有频率限制**，太频繁会被系统静默丢弃甚至报错。

- 1 小时更新一次是安全的（正好和整点碎念节奏吻合）。
- 如果用 `setTimeout` 做定时，注意服务被系统回收后定时器会丢，需在 `onStartCommand` 里重建。

## 与通知渠道

- 单独建一个低打扰的通知渠道，`IMPORTANCE_LOW`，让碎念不弹横幅、不响铃，只静静躺在通知栏。
- 这样既保活，又不会每分钟骚扰你一次。

## 触发表现

整点到了 → 更新通知文案，偶尔配合桌宠气泡里同步冒一句。
